# Edison Motors Capstone Project

A full-stack truck configuration and business management web application developed as a capstone project for Southern Alberta Institute of Technology in collaboration with Edison Motors.

## Overview

This project was designed to support Edison Motors with a digital system for configuring trucks and managing related business workflows. The application includes customer-facing and internal tools for truck configuration, sales support, employee management, and data-driven operations.

## Features

- Truck configuration workflow
- Customer and sales management features
- Employee management functionality
- Database-backed application structure
- Authentication and protected routes
- Responsive web interface
- Backend and frontend integration

## Tech Stack

- TypeScript
- JavaScript
- CSS
- Next.js
- React
- Prisma
- Supabase
- NextAuth
- Tailwind CSS

## Project Structure

- `app/` – Main application pages and routing
- `components/` – Reusable UI components
- `backend/` – Backend-related functionality
- `prisma/` – Database schema and Prisma configuration
- `supabase/` – Supabase migrations and database setup
- `schemas/` – Validation and data schemas
- `lib/` – Shared utilities
- `hooks/` – Custom React hooks

## My Role
